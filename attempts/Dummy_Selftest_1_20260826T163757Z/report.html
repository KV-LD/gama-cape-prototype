Capstone problem

1. Business Context
Horizon Merchants is a mid-market omnichannel retailer (120 stores + e-commerce) preparing a Q3 pilot to cut “wrong-item / wrong-size” returns in apparel. Leadership wants a field-deployed engineer to frame which return-reduction problems are genuinely AI-solvable versus rule- or policy-driven, so the company does not fund a model where a deterministic workflow would suffice. You are the FDE trainee assigned to produce the framing package the VP of Operations will use to green-light or kill the pilot.

2. Explicit Constraints
- Scope is limited to the existing 18-month returns and product-catalog extracts (CSV/Parquet only); no new data collection or customer PII enrichment.
- All exploratory analysis and prompt work must be done with Claude and Cursor; no hyperscaler services or managed ML platforms may be introduced.
- Deliverable package is due in five business days and must fit a 12-slide equivalent brief plus an accompanying prompt library file.
- Any recommendation that touches customer-facing messaging or size/fit advice must note applicable retail advertising and fairness expectations for protected attributes (e.g., body-size proxies).

3. Deliverable Spec
Produce a single pilot-framing package containing:
- A use-case brief (2–3 pages or equivalent slides) that enumerates 3–5 candidate return-reduction problems, explicitly labels each as AI-solvable or rule-based/deterministic, and states the concrete reason AI is or is not the right approach for that problem (evidence for AI vs Non-AI Framing).
- Within the same brief, a Responsible AI section that identifies at least one bias, fairness, or governance risk specific to apparel returns / size-fit recommendations (e.g., systematic disadvantage for certain body types or demographics) and proposes a concrete mitigation tied to that risk—not a generic disclaimer (evidence for Responsible AI Awareness).
- A reusable prompt library (Markdown or .prompt file maintained in Cursor, exercised via Claude) with structured prompts (clear instruction, context, constraints) for the AI-suited use cases; each prompt must include a short note on how it was tested against an edge case or hallucination risk (e.g., missing size chart, contradictory catalog attributes) (evidence for Prompt Engineering Discipline).

4. One Deliberate Complication
Two days into the engagement, Merchandising informs you that “size-recommendation accuracy” is now a board-level OKR, while Operations simultaneously insists that any AI component must not change the existing deterministic restocking rules for the top 200 SKUs—leaving you to reconcile a stakeholder push for an AI fit model with a hard constraint that core inventory logic remain non-AI.

# toy ranker sketch used with Claude + Cursor
def diversity_cap(items, cap=0.4):
    top = [i for i in items if i['decile'] == 10]
    limited = top[: int(len(items) * cap)]
    rest = [i for i in items if i not in limited]
    return limited + rest
